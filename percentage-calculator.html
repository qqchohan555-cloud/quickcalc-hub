Percentage Calculator

Find a percentage of a value or calculate the percentage change between two values.

What is X% of Y?

Percentage change

How to calculate a percentage

To find X percent of Y, multiply Y by X and divide the result by 100. For example, 15% of 200 is 30.

How to calculate percentage change

Subtract the original value from the new value, divide the difference by the absolute value of the original value, then multiply by 100. A positive result indicates an increase and a negative result indicates a decrease. The original value cannot be zero for this calculation.
