QUICKCALC HUB — GLOBAL ENGLISH STATIC WEBSITE (V2)

INCLUDED
- Homepage plus 5 separate calculator pages
- Salary, BMI, age, percentage, and loan calculators
- Responsive CSS and shared JavaScript
- About, Privacy Policy draft, and Contact placeholder pages
- robots.txt and sitemap.xml templates
- ads.txt placeholder notes
- Ad-space placeholders (no ad scripts included)

FREE DEPLOYMENT WITH GITHUB PAGES
1. Download and extract quickcalc-hub-v2.zip.
2. Sign in at https://github.com/ and create a public repository named quickcalc-hub.
3. Upload all extracted files and folders, preserving the structure. index.html must be at the repository root.
4. Open repository Settings > Pages.
5. Choose deployment from a branch, select main and /(root), then Save.
6. Wait for the public URL shown in Settings > Pages.
7. Test homepage and all /calculators/ links on mobile and desktop.

IMPORTANT URL CLEANUP
- Before submitting the sitemap, replace YOUR-DOMAIN.example in sitemap.xml and robots.txt with the exact live HTTPS URL.
- The pages currently omit canonical links so the site will not publish a fake canonical domain. If you later add a custom domain, add correct canonical URLs to every page.
- This repository is a static site. You can deploy free on GitHub Pages, but free hosting does not guarantee AdSense acceptance. Review the host's current terms and ad provider requirements before relying on it for commercial monetization.

BEFORE APPLYING TO ADSENSE
1. Replace the Contact email placeholder with a real address you control.
2. Tailor the Privacy Policy to the actual services and jurisdictions. If you add analytics or ads, accurately disclose them and implement any required consent controls.
3. Improve About with accurate owner/editorial details.
4. Test all calculator formulas, labels, keyboard navigation, mobile layout, and error states.
5. Add substantial, original, useful content and clear explanations; avoid publishing many near-identical thin pages.
6. Add country-specific salary calculators only after researching official tax rules and stating the applicable country and tax year.
7. Apply through the official AdSense site only when the site is ready. Add the exact publisher-provided record to ads.txt if instructed. Do not use placeholder ad code or a sample publisher ID.
8. Never click your own ads, ask others to click ads, or buy invalid traffic.

TECHNICAL NOTES
- No backend, database, build step, paid API, or login is required.
